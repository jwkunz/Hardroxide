# hardroxide-cli

The `hardroxide` command-line tool.

This is the `hardroxide` command-line tool: a generator and runtime that turns a Vivado XSA into a typed
Rust HAL crate for Zynq-7000 (validated on a PYNQ-Z2). The user guide and API
reference are at <https://jwkunz.github.io/Hardroxide/>.
